# Запись на приём к ГИП

Сайт: https://b4gga.github.io/gip-appointments/

Департамент реализации проектов АО «Россети НТЦ». ГИП: Демьянов Илья Сергеевич.

Запись по будням 09:00–18:00, перерыв 13:00–14:00. Приём 20 минут, московское время. Сотрудники входят по индивидуальной учётной записи, выбирают свободное время и скачивают талон в PDF для печати на А4. Раздел «Мои талоны» позволяет скачать талон повторно и отменить запись. ГИП видит общее расписание и закрывает отдельные интервалы.

## Размещение

Статические файлы находятся в корне репозитория. GitHub Pages публикует ветку `main`, папку `/ (root)`. Установка зависимостей и сборка не нужны. При сохранении файлов в этой ветке GitHub обновляет сайт автоматически.

Общая база и учётные записи — Supabase. Публичные параметры подключения находятся в `config.js`. Ключ publishable предназначен для браузера; доступ проверяется в базе. Секретные ключи и пароли не входят в репозиторий.

`database-setup.sql` содержит исходную схему нового проекта. В действующей базе повторно выполнять этот скрипт не требуется. `source.zip` содержит полный исходный проект с тестами, локальным сервером и подробной инструкцией по установке.

## Пользователи

Администратор создаёт учётные записи через Supabase → Authentication → Users → Add user → Create new user. Самостоятельная регистрация отключена. Для предоставления роли ГИП владелец базы добавляет User UID в `gip_private.admins`. Пароли выдаются индивидуально и в репозитории не хранятся.

## PDF

В PDF встроен Noto Sans с кириллицей. PDF формируется в браузере; сторонние PDF-сервисы и CDN не используются. Библиотеки: pdf-lib 1.17.1 и @pdf-lib/fontkit 1.1.1 (MIT). Шрифт: Noto Sans (SIL OFL). Лицензии находятся в корне репозитория.

Календарь государственных праздников, почтовые уведомления и синхронизация с внешними календарями не предусмотрены. Действующая запись определяется данными сайта; после отмены ранее распечатанный талон не подтверждает приём.
